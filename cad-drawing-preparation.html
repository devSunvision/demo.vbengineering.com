2D CAD Drawings

2D drawing is a drawing that represents only in X and Y-axis. More simply, a 2D drawing is flat and has a width but no depth or thickness. 2D drawing representation is also called Orthographic representation (Front, Top, Right side, Left side, back, and bottom views). Projection representation is based on quadrants like the first and third quadrants. The orthographic views convey the most important information about a part's geometry.
